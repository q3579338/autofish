# 三角洲行动 · 自动钓鱼

## 傻瓜式（推荐）

1. 打开 [Releases](https://github.com/q3579338/autofish/releases) ，下载 `AutoFish-windows.zip`
2. 解压整个文件夹（不要只拷 `AutoFish.exe`，旁边的 `_internal` 必须留着）
3. 先打开游戏，走到水边，拿出鱼竿
4. 双击 `AutoFish.exe`，黑窗口里直接回车（默认台钓）
5. 用鼠标点一下游戏窗口把它切到最前面

- **F8** 暂停 / 继续
- **F9** 退出
- 游戏窗口不在前台时不会发任何按键
- 打开背包 / 离开钓鱼界面超过 90 秒会自动退出

Windows 若提示「未知应用」，点「更多信息」→「仍要运行」。

## 从源码运行

双击 `run.bat`，选模式（目前只有 **1 台钓** 可用，路亚待做），然后切回游戏窗口，人物手持鱼竿站在钓点即可。
命令行可直接 `python autofish.py --mode 台钓` 跳过选择。

- **F8** 暂停 / 继续
- **F9** 或控制台 Ctrl+C 退出
- 游戏窗口不在前台时不会发任何按键
- 打开背包 / 离开钓鱼界面超过 90 秒会自动退出

## 原理

| 环节 | 感知方式 |
|---|---|
| 咬钩 | 系统声音环回，与 `assets/bite_wave.npy`（录下的咬钩音效）做归一化互相关，阈值 0.6（实测真咬钩 ≥0.88，其他声音 <0.3） |
| 空闲 / 待咬钩 | 截屏右下提示区做 OCR（RapidOCR），读到「抛竿」为空闲、「退出钓鱼 / 刺鱼」为线在水里、「收线 / 摆杆」为路亚拉鱼（脚本不处理）。对提示位置、行数、背景亮度不敏感，换钓点不用改 |
| 动作 | `SendInput` 鼠标左键 |

## 可调参数（`autofish.py` 顶部）

- `BITE_REACT_DELAY` 咬钩确认后再等几秒刺鱼，默认 0.5（合计约在咬钩音响起 0.8 秒后刺）。宁晚不早，觉得晚了可调到 0.2。
- `POST_REEL_DELAY` 刺鱼后等动画的秒数，默认 4.5。
- `MAX_CATCH` 钓够几条自动停，0 为不限。
- `DEBUG_STATES` 打印提示区状态跳变，排查用。

## 已知限制

- 提示区截取范围按 **2560×1440 全屏** 标定（`HUD_REGION`）；换分辩率只需改这一个矩形。
- 路亚模式未实现：检测到「收线/摆杆」时脚本只等待，请手动拉鱼。
- 音频模板来自默认输出设备（PRO X 2 LIGHTSPEED）的环回；换输出设备不用改，但游戏音效音量为 0 会抓不到。
- 背包满不会自动停（游戏仍能继续钓），需要时把 `MAX_CATCH` 设成条数。
- 这是宏，ACE 反作弊可能判定为外挂，封号风险自负。
